Veda Technology — Task 29: Basic Conditional Formatting

Objective

Use Excel conditional formatting rules to highlight top and bottom values automatically and improve report readability.

Dataset

This workbook uses a sample retail sales dataset created for practice with 60 sample orders. It is not real customer or company data.

Workbook sheets

• Summary — key sales metrics and a legend for the highlights.
• Raw Data — sample order-level data with conditional formatting applied.
• Rules List — documents each conditional formatting rule and its purpose.
